# simple-js-todo
A simple, clean, and interactive To-Do List application built entirely using HTML,CSS, and JavaScript. Features include adding/deleting tasks, marking tasks as done/undone, and dynamic visibility on hover.


Features:
Add Tasks: Easily add new tasks via the input field.
Mark as Done/Undone:** Use the "Done" button to toggle the task status.
Delete: Permanently remove tasks from the list.
Dynamic UI: Buttons (Done/Delete) become visible only when hovering over a list item (`<li>`).

Technologies Used:
* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
  
How to Run:
Open the `index.html` file in your web browser.
